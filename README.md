# Gordinho da IA — Landing Page

Página de teste para a **Comunidade Claude** por Daniel Feitosa.

## Stack

- HTML único (sem build tools)
- Tailwind CDN
- Canvas API para rede neural animada
- Google Fonts (Playfair Display, Inter, Space Mono)

## Features

- Rede neural interativa no fundo (reage ao mouse)
- Cursor personalizado com anel seguidor
- Efeito typewriter com rotação de frases
- Contadores animados com IntersectionObserver
- Cards com tilt 3D e blur em irmãos
- Botões magnéticos com efeito shimmer
- Barra de progresso de scroll
- Totalmente responsivo e compatível com GHL
